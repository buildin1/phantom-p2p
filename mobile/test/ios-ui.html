交给实现的约束

handoff
稿中构件SwiftUI 对应说明
四标签容器TabView + 每标签一个 NavigationStack每个标签各自维护导航栈，切回时保留位置
大标题导航栏.navigationBarTitleDisplayMode(.large)滚动自动收成 44pt；副标题用 .toolbar 的 principal 项
分组内嵌列表List { Section { } } + .listStyle(.insetGrouped)解释文字一律走 Section footer，不做行内副标题
开关Toggle + .tint(.ember)用品牌炭橙而非系统绿——绿在本设计里专属「已连接」
半高弹层.sheet + .presentationDetents([.medium, .large])配 .presentationDragIndicator(.visible)
操作表.confirmationDialog破坏性项用 role: .destructive
分段控件Picker + .pickerStyle(.segmented)诊断页三视角
接线台动效withAnimation + .phaseAnimator必须判 accessibilityReduceMotion，减弱时停在稳态
连接状态enum，不是字符串idle / probing / punching / tunneling(Transport) / failed(Reason)；展示文案从它派生
状态源@Observable 模型 + @State 持有不用 ObservableObject；副作用进 .task，随视图取消
字号全部用文本样式（.body / .title）稿中标注的 pt 是默认档；必须支持动态字体
数字.monospacedDigit()延迟、耗时、IP、房间码一律等宽，避免跳动
  • 不出现在 iOS 的东西：FAB、Snackbar、Material 卡片阴影层级、Android 的「后台存活」设置组。反过来，iOS 的「按需连接」「左滑操作」「操作表」也不搬去 Android。
  • 引擎在扩展进程里：本稿全部界面属于主 App，只是遥控器。真正的隧道跑在 Packet Tunnel Provider 扩展中，状态经 NETunnelProviderSession 推回来。界面必须能承受「扩展在跑、App 刚被拉起、状态还没到」这一帧——首帧显示上次已知状态并标记为陈旧，不要空白。
  • 本稿不含：首启引导、VPN 配置安装弹窗（由系统绘制）、开发者选项。
