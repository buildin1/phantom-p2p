接线台：Android 端视觉稿

重写前的设计定稿。基调取自物理跳线盘——把两台隔着 NAT 的机器接成一条线，是这个产品唯一在做的事，所以界面的主角是那条线本身。配色离开桌面端的蓝玻璃：暖石墨底、炭橙作品牌与交互色、玉青专用于「已连接」。橙色永不表示状态，只表示品牌与进行中。

交给实现的约束

handoff
项约定为什么
传输标签只出现 P2P 直连 (UDP) 与 P2P 直连 (QUIC)界面不出现「中继」，避免使用心理阻碍；内部状态机仍精确区分
连接状态Kotlin sealed interface，不用字符串展示文案从状态派生；旧实现用自由文本同时做展示与判断，已证明会错
MTU界面显示与 VpnService 都用 1160与 core 的 TUN_MTU 对齐，QUIC datagram 可用载荷实测 1162
动效接线台三态共用同一构件，只换色与运动状态切换不跳版；同时尊重系统的「减弱动态效果」
主题深浅两套完整令牌，不做动态取色品牌辨识优先于 Material You 取色；两端要看起来是同一个产品
字体Roboto / Roboto Mono + 系统中文字体数字一律等宽对齐（延迟、IP、房间码、耗时）
  • 与 iOS 稿的关系：信息架构、四个标签、接线台构件、配色与文案完全一致；差异只在系统构件——Android 用顶部应用栏 + M3 导航栏 + FAB + Snackbar，iOS 用大标题导航栏 + 分组内嵌列表 + 标签栏 + 操作表。见 ios-ui.html。
  • 本稿不含：开发者选项（dev flavor 专有）、首启引导、VPN 权限系统弹窗（由系统绘制）。
